Transport Agent DLP Flow

One email through the DLP pipeline, transport agent option

A custom transport agent running inside Exchange pauses each outbound message and sends it to watsonx Orchestrate for scoring. There is no extra SMTP hop. The analysis is saved to the analysis DB in watsonx.data, the agent stamps X-Watsonx-Classification and releases the message, and SMG and Network Prevent for Email act on it. When Enforce opens an incident, it is matched back to the database row by Message-ID. Reviewer decisions are written back to the analysis DB and feed into Orchestrate's next scores.
